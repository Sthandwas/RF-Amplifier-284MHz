# Narrowband RF Amplifier (284 MHz)

A single-stage narrowband RF amplifier designed for a 50 Ω system operating at 284 MHz, built around a BFP420 transistor. The design was simulated in Cadence AWR Design Environment and the completed circuit was tested.

Course project: RF Engineering (RFEB 301), Durban University of Technology, 2026.

## Measured performance

| Parameter | Result |
|---|---|
| Centre frequency | 284 MHz |
| Gain | 21.07 dB |
| Input return loss | 16.16 dB |
| Output return loss | 16.17 dB |
| System impedance | 50 Ω |
